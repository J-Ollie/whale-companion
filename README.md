# 小鲸鱼 🐋

小鲸鱼是一个基于 AstrBot、QQ 接入端和安卓备用机的个人陪伴项目。它尝试把聊天、可追溯记忆、作息和经授权的自主活动连接起来，让回复与行动都有上下文和边界。

本仓库展示经过脱敏整理的源码，**不是一键安装包，也不包含运行中的实例或私人数据**。本次源码同步至 2026-11-04 的本地维护版本；管理中心目录保留此前公开版本，不能代表当前部署的网页。

## 现在有哪些能力

- **统一 QQ 聊天：** 好友申请与身份核验、按联系人合并消息、自然收尾、主动联系、睡眠未读与可选语音，由 `astrbot_plugin_companion_chat` 协调。不同功能保留各自开关、权限和额度；休息或睡眠期间按既有规则处理未读。
- **分层记忆与场景：** 记忆按联系人、公开资料与获准群等范围区分，保留原话来源、版本与有效性。可检索事实、计划、经历、原文和场景背景；遗忘、更正和失效会影响后续召回。检索未命中不代表事情没有发生。
- **情绪与缓慢成长：** 联系人相关的短期情绪和跨日表达变化依赖实际互动及预算；系统状态是程序中的建模和表达依据，不等于可以证明人的主观体验。
- **可选语义检索：** 在现有记忆库之外维护按范围隔离的可读投影和语义候选，结合全文检索进行排序。需要单独启用、配置嵌入服务及预算；不启用时不能假定语义功能可用，也不保证召回准确。
- **备用机与自主社交：** 手机插件提供受授权和配额约束的观察、应用操作、阅读、图片、作息及日记能力。QQ 空间与个人资料的新操作通过外部 QQ空间Ultra、QQProfile 插件及兼容层执行；是否实际完成以操作回执为准。
- **多模态与语音：** 统一聊天可接入 Breeze 语音回复，另有百炼语音识别适配器。语音、识图和视频理解依赖独立插件、服务及配置，源码存在并不表示每项能力都已启用或可复现。

## 部署与安全边界

1. 自行准备兼容的 AstrBot、QQ 接入端、Python 环境和模型服务；手机功能另需安卓设备、ADB 和私有网络。
2. 完整复制所需插件目录，**不要只复制统一聊天目录顶层文件**。启用统一聊天前，先停用旧的独立聊天调度插件，避免重复处理消息；具体迁移、状态和配置需要在自己的环境中验证。
3. 自行配置管理员和机器人账号、平台、模型、授权软件与各功能预算。仓库中的账号、地址和语音标识是示例，不能连接原实例。
4. 按需安装并配置语音、语义索引、第三方 QQ 空间与资料插件；检查它们各自的许可证、权限、版本与接口。第三方项目、个人素材和凭据不随本仓库提供。
5. 先在隔离环境验证联系人隔离、睡眠未读、工具权限和操作回执，再考虑实际账号。不要用示例或历史备份覆盖已有实例、数据库和登录状态。

## 验证

项目测试需要对应的 AstrBot 及插件运行依赖。可先运行与改动有关的隔离测试，例如：

```bash
export COMPANION_TEST_PLUGINS="$PWD/astrbot-plugins"
python -m unittest discover -s tests -p 'test_memory_scenes.py' -q
```

部分测试依赖 Linux、AstrBot 内部接口或已退役组件，不能假定所有测试可在空白 Windows 环境直接通过。模拟测试、模型生成内容或操作意图都不等于真实 QQ 消息送达、手机操作成功或对外可见。

## 隐私与许可

本仓库不提供密钥、登录态、聊天、私人记忆、日记、相册和运行数据库。项目按真实联系人隔离私人信息，管理员有权查看不意味着可以向其他联系人或公开渠道复述。公开仓库中早期管理中心源码仍然可见；仓库更新不会自动部署到现有网站。

第三方软件与素材适用各自的许可证；本项目自有代码尚未统一指定开源许可证，公开展示不等于自动授予再分发权。
