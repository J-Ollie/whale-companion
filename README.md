# 小鲸鱼 · 岚 🐋

一个在 QQ 中逐渐积累经历的 AI 陪伴项目，基于 AstrBot，连接云服务器、安卓备用机与网页管理中心。

本仓库分批整理当前成果。每批独立提交，已经上传的内容可以立即查看。当前是项目归档和开发参考，尚未整理成开箱即用的一键部署包。

## 已实现的方向

- **记忆与成长**：近期对话、有原话依据的长期记忆、可修正的人物印象、共享身份与性格，以及按对象隔离的私聊内容。
- **时间与日记**：作息状态、睡眠期间暂存消息、醒来后处理未读，以及公开和私密两类日记。
- **手机活动**：通过私有网络和 ADB 连接安卓备用机，在授权应用中浏览、搜索、滑动和使用图片。
- **社交互动**：好友申请须由管理员审批；好友私聊；在配置许可与配额内发表空间动态、点赞和回复评论。
- **管理中心**：连接检查、登录恢复入口、好友聊天记录、日记、档案、访客自愿昵称和私密留言。
- **访客隐私**：同一来源短期合并来访，不记录具体浏览栏目；留言仅管理员和小鲸鱼读取。

## 结构与依赖

运行形态为：QQ 接入端 → AstrBot → 陪伴插件；网页管理服务独立运行。手机控制经 Tailscale 私有网络连接 ADB。模型服务、QQ 接入端、AstrBot 与 Tailscale 均需单独配置。

源码与文档正在逐批发布，具体批次见 [上传记录](docs/UPLOAD_PROGRESS.md)。各插件不是完全独立的安装包，需结合部署说明和相互依赖使用。
