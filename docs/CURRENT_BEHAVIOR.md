# 当前设计与配置意图

这些是当前实例逐步确定的行为目标，部分由运行配置控制。部署到新环境时应主动配置并测试，不能将源码 schema 默认值视为完整配置。

- 名字、整体性格与已确认的公开关系可跨好友对话共享；具体私聊内容、私人经历和私密日记不能向其他联系人披露。
- 姓名、性格、已保存记忆及整理进度独立持久化，新窗口不清空。有限近期窗口配合按意思相关的关键词检索；过期计划保留历史，不默认已完成。预算和算法见 MEMORY.md。
- 睡眠时不读取并回复新消息；消息进入待处理队列，醒来后再处理。睡眠也延后管理员交代的手机任务，早期“命令覆盖睡眠”规则已撤回。
- 允许在自然结束话题后选择不回，例如对结束语的简单确认；对带有告别含义的新话语可简短收尾，避免机械静默或无限互道晚安。
- 自主手机访问每次最多10分钟、每日最多10次；管理员聊天中明确交代的访问不计入自主访问次数。允许观察、刷新、搜索和滑动。
- 可配置访问天气、相册、日历、酷安、QQ、哔哩哔哩、百度贴吧、Neat Reader 和 Via。相册内容须先预览再发送，访问范围和识别授权应由部署者确认。
- 空间动态每日最多5条，没有原来的两小时间隔要求；内容与配图可由模型决定。实际发布结果必须与回执/回读关联，不能另外编造“自己刚发的文案”。
- 点赞、评论等能力受独立授权控制；付费提示、误触或内容审核失败需要识别，不能凭点击坐标假定完成。
- 好友申请在通知前尽力查询真实QQ和昵称；身份未知时不允许同意，可用 `/核对好友 编号` 重查。管理员看到具体QQ后单独同意才通过；非好友不能进行普通私聊。审批通知不占每日主动联系管理员的次数。
- 自主分享有趣内容到管理员 QQ 每日最多3条；不应为完成配额强行凑话题或频繁报告“先看看手机状态”。
- 日记分公开总结与私密笔记，23:30起整理，睡眠延后，平淡也能写。选择不写留简短原因，失败待重试；公开请求不加载私聊正文和私密笔记。
- 访客昵称和留言自愿填写。留言仅管理员和小鲸鱼可读；最近来访在公网按同一 IP 的私有加盐摘要合并30分钟内访问，不记录具体浏览栏目。本地隧道无法获知真实来源时回退匿名浏览器标识。

上述自主行为由调度、持久化状态、模型和工具共同实现。权限文案、配置和执行检查需保持一致；仅在角色卡里写“你可以”不会自动授予工具权限。

- 连续浏览允许一次滑动1至5下，结束后观察；点按和输入仍需当前画面依据。
- 消息合并为最后一条后等待15秒、从本批第一条起最多60秒；不含模型与发送耗时。
- 第三方表情包插件的运行概率门槛为25%，通常只用文字；该插件本身未包含在仓库，不能仅安装本项目即得到相同配置。
- 网站的ADB连通探测与角色睡眠分开：只维护已配对连接，不唤醒、截图或操作应用，不表示恢复管理员任务打断睡眠。
- 小声话与活动时间段是公开表达和倾向，不是活动回执。账单只显示已核对的官方数据，未知或登录态失效不当作余额／费用为零。
